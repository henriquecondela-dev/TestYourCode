mettodo para adicinar uma fucnoa a pagina.. o  appendchild
.appendChild(....);
O método .appendChild() em JavaScript serve para adicionar um elemento HTML como filho de outro elemento.

Sintaxe
elementoPai.appendChild(elementoFilho);
elementoPai → o elemento que vai receber o novo elemento.
elementoFilho → o elemento que será adicionado.
Exemplo simples

HTML:

<div id="container"></div>

JavaScript:

const container = document.getElementById("container");

const p = document.createElement("p");
p.textContent = "Olá, mundo!";

container.appendChild(p);

Resultado:

<div id="container">
    <p>Olá, mundo!</p>
</div>

O parágrafo foi adicionado dentro da div.
